# 精选短文生成流程

> 路径约定：本文命令均在项目根目录执行；主页面、词库和 `.env` 仍在根目录，现行说明位于 `docs/`。目录调整不改变业务规则、第三方许可或材料上传白名单。


本流程连接正式 HTML 词库、外部检索、正文获取、统一模型层和 `reading_materials/` 资料库。阅读页面会把本地合格 Markdown 加入随机候选池；打开和换文章都不联网。生成流程不会直接向正式词库添加候选词。

## 数据流与安全边界

1. 从 `vocabulary.html` 的正式词卡读取已收录词，并与 `learned_words.json` 派生索引核对。
2. 使用 Tavily 检索并转换为规范化来源数据。检索与模型生成相互独立，不把“模型自带搜索”当作前提。
3. 优先取得网站正文；Tavily 返回的可用正文可直接使用，否则只访问公开 HTTPS 网页。重定向逐次检查，拒绝本机、内网地址、非文本内容和超大响应。脚本、样式与 HTML 标签只被删除，网页内容绝不执行。
4. `input` 和用户长文可以作为辅助资料，但必须附 HTTPS 来源链接并标记为 `input_file` 或 `user_input`。提示词把全部来源明确标记为不可信资料，网页中的指令不会成为程序指令。
5. 选定 DeepSeek 及具体模型后，模型先返回受约束的结构化草稿。程序补充稳定 ID、日期、难度、来源和制作方式，再调用现有资料库规则校验。
6. 校验覆盖 5/20/45 分钟长度、至少 4 个已收录词和 2 个新词、1–5 道题且至少一道词义题、候选词卡字段、HTTPS 来源、重复字段及固定 Markdown 格式。失败只在同一供应商和模型上有限重试，不自动切换。
7. 完整 Markdown 先在内存中生成并再次解析，通过后以“待人工审核”状态写入同目录临时文件、同步并原子改名。相同正文，或同一来源下的相同正文，均拒绝重复入库。
8. 待审核和审核不通过的材料不进入随机候选池。人工核对来源、事实、题目、答案、词性、音标、释义和例句后，将状态改为“已人工审核”才允许展示。
9. 新文件成功落盘后，按“档位 + 难度”计算模型材料保留候选。页面仅列出候选并等待用户确认，不会在生成或打开文章时自动删除。

## 可程序检查与内容质量

程序可以检查格式、字段、长度、词汇覆盖、唯一正确选项、来源格式和重复内容。它不能保证文章事实、题目推理、词性判断、音标、翻译或词典释义一定正确。模型生成材料在正式使用前必须人工审核；阅读候选仅在词义题答错并保存时建卡。另有独立的翻译候选经用户核对确认入库路径，翻译不使用本生成流程，不调用 Tavily。

## 本地配置

复制 `.env.example` 为不受版本管理的 `.env`，设置 `TAVILY_API_KEY`、`DEEPSEEK_API_KEY`、允许模型和默认模型。接口参考：[Tavily Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search)。真实生成前，由用户明确把 `READING_ALLOW_EXTERNAL_CALLS` 改为 `true`；页面仍要求逐次确认可能产生费用。

请求上限由 `READING_MAX_SEARCH_REQUESTS`、`READING_MAX_ARTICLES_PER_RUN` 和 `READING_VALIDATION_RETRIES` 控制；`READING_MAX_SOURCE_CHARS` 限制一次发送给模型的来源正文总字符数。`READING_GENERATED_RETENTION_PER_SLOT` 设置每个“档位 + 难度”最近模型材料的保留数，默认 3；它只影响确认式清理候选。汇总用量默认写入本地 `.reading-generation-usage.jsonl`，只记录服务、模型、次数、令牌、来源字符数和文件名，不记录密钥、提示词或正文。

清理候选必须同时满足：模型生成、普通保留策略、超过同槽位上限、不是当前阅读、没有待保存错词，并且删除后仍有审核通过的材料覆盖该槽位。人工/用户/手工迁移和指定保留材料不参与。用户确认时服务重新解析精确文件；状态变化或删除失败只会保留该文件并返回原因，不影响新材料、正式词库或浏览器记录。由于服务无法可靠获知其他浏览器配置中的未完成答题，当前不启用无人确认的自动删除。

费用字段分为 `kind: estimate` 与 `actualCostUsd: null`。估算使用代码内带日期的价格快照，只用于调用前后量级参考；实际费用必须以供应商账单为准，不能从令牌数精确推断。

## 模拟验证与真实联调

`npm run test:generation` 使用模拟 Tavily、网页和 DeepSeek 响应，不发送外部请求、不产生付费。真实联调还需要配置两项密钥、确认允许模型名称、开启外部调用开关，并在获得当次预算授权后用小上限运行，再人工核对来源、正文、题目与供应商账单。
